# E-commerce Sales Analysis

## Project Overview

This project focuses on analyzing Brazilian e-commerce sales data to identify sales trends, top-performing product categories, customer purchasing patterns, and customer satisfaction.

The analysis was performed using Python and Power BI to transform raw e-commerce data into meaningful business insights through data cleaning, exploratory data analysis (EDA), and interactive visualizations.

## Objectives

- Analyze overall e-commerce sales performance.
- Identify monthly revenue trends.
- Find the highest revenue-generating product categories.
- Analyze revenue by customer state.
- Understand customer purchasing behavior.
- Evaluate customer satisfaction through review scores.
- Build an interactive Power BI dashboard.

## Dataset

**Brazilian E-Commerce Public Dataset by Olist**

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about:
- Customers
- Orders
- Order items
- Products
- Payments
- Customer reviews

The dataset covers Brazilian e-commerce transactions from 2016 to 2018.

## Project Workflow

### 1. Data Loading
- Imported multiple CSV datasets using Pandas.
- Explored dataset structures and column information.

### 2. Data Cleaning
- Checked missing values.
- Checked duplicate records.
- Converted date columns into datetime format.
- Handled missing product categories.
- Filtered delivered orders for the main sales analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyzed yearly and monthly revenue.
- Identified top-performing product categories.
- Analyzed revenue by customer state.
- Examined customer review scores.
- Evaluated customer satisfaction.

### 4. Data Visualization
Created visualizations using Matplotlib and Seaborn to identify patterns and trends.

### 5. Power BI Dashboard
Developed an interactive dashboard containing:

- Total Revenue
- Total Orders
- Average Order Value
- Unique Customers
- Monthly Revenue Trends
- Top 10 Product Categories
- Revenue by Customer State
- Customer Review Distribution
- Customer Satisfaction Analysis

## Key Business Questions

1. How does revenue change over time?
2. Which product categories generate the highest revenue?
3. Which customer states contribute the most revenue?
4. What is the average order value?
5. How satisfied are customers with their purchases?
